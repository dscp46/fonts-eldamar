# fonts-eldamar
Debian package for Måns Björkman's Eldamar font

Eldamar is a typeface designed by Måns Björkman Berg supporting the
writing systems invented by J.R.R. Tolkien: Tengwar, Valmaric, Sarati
and the Pre-Feanorian alphabets (Qenyatic, Falassin, Noriac, Banyaric
and Sinyatic), as well as the New English Alphabet.

The writing systems are encoded in the Unicode Private Use Area
(U+E000-U+F8FF) following the ConScript Unicode Registry (CSUR)
conventions, with supplementary punctuation in the Basic Latin and
Supplemental Punctuation ranges.

This package installs the font together with a fontconfig configuration
that registers Eldamar as the default family for CSUR Tengwar text.
