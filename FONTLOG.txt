Basic Font Information

Eldamar is a typeface that supports the writing systems Tengwar, Valmaric, 
Sarati and the Pre-Feanorian alphabets (Qenyatic, Falassin, Noriac, Banyaric, 
and Sinyatic), as well as the New English Alphabet, all invented by and 
described in the works of J.R.R. Tolkien.

The Writing systems of Tolkien are encoded in the Unicode Private Use Area 
(E000-F8FF). Some supplementary punctuation, required for writing Tengwar, 
are encoded in the ranges C0 - Controls and Basic Latin, and 
2E00 - Supplemental Punctuation.

This release contains:

* Eldamar1_1.otf - The font file
* Eldamar1_1-doc.pdf - The documentation file
* FONTLOG.txt - This log file
* OFL.txt - The SIL Open Font License file
* OFL-FAQ.txt - OFL Frequently Asked Questions

* Reporting bugs or errors of any kind in the font
